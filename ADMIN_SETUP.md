# Настройка админ-панели для обучения ИИ

## Требования

1. Переменные окружения в `.env.local`:
   - `API_GPT` - токен OpenAI API
   - `NEXT_PUBLIC_SUPABASE_URL` - URL вашего Supabase проекта
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` - анонимный ключ Supabase
   - `SUPABASE_SERVICE_ROLE_KEY` - **РЕКОМЕНДУЕТСЯ** service_role ключ для операций удаления (обходит RLS)

   **Важно:** Для корректного удаления разделов и связанных данных рекомендуется добавить `SUPABASE_SERVICE_ROLE_KEY` в `.env.local`. Этот ключ можно найти в настройках проекта Supabase (Settings → API → service_role key). Без него удаление может не работать из-за RLS политик.

## Настройка Supabase

### 1. Установка расширения pgvector

Выполните в SQL Editor вашего Supabase проекта:

```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

### 2. Создание таблиц

Выполните весь скрипт из файла `supabase-setup.sql` в SQL Editor Supabase.

Этот скрипт создаст:
- Таблицу `ai_sections` для разделов обучения
- Таблицу `ai_vectors` для векторных данных с эмбеддингами
- Индексы для быстрого поиска
- Функцию `match_vectors` для поиска похожих векторов

### 3. Настройка RLS (опционально)

По умолчанию таблицы настроены для чтения всеми. Если нужна дополнительная безопасность, настройте Row Level Security политики в Supabase Dashboard.

## Использование

1. Запустите проект: `npm run dev`
2. Перейдите на `/admin`
3. Войдите с логином `admin` и паролем `19791979`
4. Создайте раздел для обучения ИИ
5. Выберите раздел и загрузите видео/аудио файл
6. Система автоматически:
   - Транскрибирует видео через Whisper API
   - Разобьет текст на чанки
   - Создаст эмбеддинги для каждого чанка
   - Сохранит в Supabase в векторном формате

## Архитектура

- **Разделы** (`ai_sections`) - изолированные базы знаний
- **Векторные данные** (`ai_vectors`) - чанки текста с эмбеддингами
- **Поиск** - функция `match_vectors` для семантического поиска

## Интеграция с n8n

Для использования в n8n:
1. Используйте функцию `match_vectors` для поиска релевантных чанков
2. Передайте запрос пользователя и получите похожие векторы
3. Используйте найденные чанки для формирования контекста для LLM

Пример запроса в n8n:
```sql
SELECT * FROM match_vectors(
  query_embedding := '[ваш эмбеддинг запроса]',
  match_section_id := 'uuid-раздела',
  match_threshold := 0.5,
  match_count := 5
);
```

## Устранение проблем

### Ошибка при сохранении векторов

Убедитесь, что:
1. Расширение `pgvector` установлено
2. Таблица `ai_vectors` создана с правильной структурой
3. Поле `embedding` имеет тип `vector(1536)`

### Ошибка транскрибации

Проверьте:
1. Токен OpenAI API валиден
2. Файл в поддерживаемом формате (mp3, mp4, wav, и т.д.)
3. Размер файла не превышает лимиты OpenAI (25MB)
