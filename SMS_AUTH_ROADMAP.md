## Технические детали

### Формат номера телефона
- Входной формат: `+7XXXXXXXXXX` или `7XXXXXXXXXX` или `8XXXXXXXXXX`
- Формат для SMS.ru: `+7XXXXXXXXXX` (обязательно с +7)

### Формат SMS сообщения
```
Ваш код подтверждения: 1234
Код действителен 5 минут.
```

### Структура таблицы `sms_codes`
```sql
CREATE TABLE sms_codes (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  phone VARCHAR(20) NOT NULL,
  code VARCHAR(6) NOT NULL,
  expiresAt DATETIME NOT NULL,
  attempts INT DEFAULT 0,
  isUsed BOOLEAN DEFAULT FALSE,
  createdAt DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_phone (phone),
  INDEX idx_code (code),
  INDEX idx_expiresAt (expiresAt)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### Пример API запроса к SMS.ru
```typescript
POST https://sms.ru/sms/send
{
  "api_id": "YOUR_API_KEY",
  "to": "+79161234567",
  "msg": "Ваш код: 1234",
  "json": 1
}
```

## Переменные окружения

Добавить в `.env.local` и продакшн:
```env
# SMS.ru API
API_ID_SMS=your-api-key-here
SMS_SENDER_NAME=YANA  # Имя отправителя (после подтверждения)
SMS_CODE_EXPIRY_MINUTES=5  # Время жизни кода в минутах
SMS_MAX_ATTEMPTS=5  # Максимум попыток ввода кода
SMS_RATE_LIMIT_PER_HOUR=3  # Максимум SMS в час на номер
```
