# Отладка проблемы на стороне клиента

## Проблема

Запрос POST к `/api/admin/transcribe` не появляется в логах nginx - значит запрос не доходит до сервера.

## Диагностика

### 1. Откройте консоль браузера (F12)

После обновления кода с логированием на клиенте, откройте консоль браузера и попробуйте загрузить файл.

Должны появиться логи:
- `[ADMIN] Starting file upload:`
- `[ADMIN] FormData created, sending fetch request...`
- `[ADMIN] Fetch response received:`

### 2. Проверьте вкладку Network

1. Откройте DevTools (F12)
2. Перейдите на вкладку **Network**
3. Попробуйте загрузить файл
4. Найдите запрос к `/api/admin/transcribe`
5. Проверьте:
   - Отправляется ли запрос вообще?
   - Какой статус (pending, failed, cancelled)?
   - Есть ли ошибка в консоли?

### 3. Возможные проблемы на клиенте

#### Проблема 1: Запрос не отправляется
- Проверьте консоль браузера на ошибки JavaScript
- Проверьте что файл выбран и sectionId установлен

#### Проблема 2: Запрос отправляется, но блокируется
- Проверьте CORS ошибки в консоли
- Проверьте что нет блокировщиков рекламы/расширений браузера

#### Проблема 3: Запрос отправляется, но не доходит до сервера
- Проверьте что URL правильный (`/api/admin/transcribe`)
- Проверьте что нет проблем с сетью

### 4. Проверьте что приложение работает

```bash
# Проверьте что Next.js отвечает
curl -I http://localhost:3000/api/admin/auth

# Должен вернуть 200 или 401, но не ошибку соединения
```

### 5. Попробуйте прямой запрос

Откройте консоль браузера на странице `/admin` и выполните:

```javascript
const formData = new FormData();
formData.append('file', new File(['test'], 'test.txt'));
formData.append('sectionId', 'test-id');

fetch('/api/admin/transcribe', {
  method: 'POST',
  body: formData
}).then(r => console.log('Response:', r)).catch(e => console.error('Error:', e));
```

Это покажет, отправляется ли запрос вообще.

## Решение

После проверки консоли браузера и Network tab, пришлите:
1. Что показывает консоль браузера (логи с префиксом [ADMIN])
2. Что показывает Network tab (статус запроса)
3. Есть ли ошибки в консоли

Это поможет понять, где именно происходит проблема.
