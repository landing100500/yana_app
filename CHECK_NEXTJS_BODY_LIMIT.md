# Проверка лимита body в Next.js

## Проблема

Запрос не доходит до обработчика - логи не появляются вообще. Локально работает, на сервере нет.

## Возможные причины

1. **Next.js имеет лимит на размер body** - по умолчанию может быть ограничение
2. **Проблема с production режимом** - Next.js в production может обрабатывать body по-другому
3. **Проблема с nginx** - запрос не доходит до Next.js

## Диагностика

### 1. Проверьте что запрос доходит до Next.js

После обновления кода с логированием в начале POST функции, проверьте:

```bash
sudo -u nodejs pm2 logs yana_app --lines 0
```

Если видите `[TRANSCRIBE] ===== POST HANDLER CALLED =====` - запрос доходит до Next.js.
Если не видите - проблема в nginx или запрос не отправляется.

### 2. Проверьте логи nginx

```bash
sudo tail -f /var/log/nginx/access.log
```

Попробуйте загрузить файл и посмотрите, появляется ли запрос в access.log.

### 3. Проверьте ошибки nginx

```bash
sudo tail -f /var/log/nginx/error.log
```

### 4. Попробуйте маленький файл

Попробуйте загрузить файл размером 1MB. Если работает - проблема в размере.

### 5. Проверьте что приложение запущено

```bash
sudo -u nodejs pm2 status
curl http://localhost:3000/api/admin/transcribe -X POST -H "Content-Type: multipart/form-data" -v
```

## Решение: Проверка переменных окружения

Next.js может использовать переменные окружения для лимитов. Проверьте `.env.production`:

```bash
cd /var/www/yana_app
cat .env.production
```

## Альтернативное решение: Использовать другой endpoint для загрузки

Если проблема в лимите body, можно:
1. Загружать файл через отдельный endpoint (chunked upload)
2. Использовать прямую загрузку в S3/объектное хранилище
3. Использовать streaming подход

Но сначала нужно понять, доходит ли запрос до Next.js вообще.
