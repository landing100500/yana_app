# Настройка переменных окружения для Vercel

Для корректной работы приложения на Vercel необходимо настроить следующие переменные окружения:

## Обязательные переменные

### База данных MySQL
```
DB_NAME=optsetkh_main
DB_USER=optsetkh_main
DB_PASSWORD=100100Main
DB_HOST=optsetkh.beget.tech
```

### JWT Secret
```
JWT_SECRET=yasna-secret-key-change-in-production
```
**ВАЖНО**: В продакшене используйте случайную строку для безопасности!

### Node Environment
```
NODE_ENV=production
```
(Обычно устанавливается автоматически на Vercel)

## Опциональные переменные

### N8N Webhook URL (для чата с ИИ)
```
N8N_WEBHOOK_URL=https://n8n.konstantinluksha.ru/webhook/26e44a79-465d-4644-a367-3db29217edf6
```
Если не указано, будет использоваться значение по умолчанию из кода.

## Как добавить переменные в Vercel

1. Откройте проект в Vercel Dashboard
2. Перейдите в **Settings** → **Environment Variables**
3. Добавьте каждую переменную:
   - **Name**: имя переменной (например, `DB_NAME`)
   - **Value**: значение переменной
   - **Environment**: выберите `Production`, `Preview`, и/или `Development`
4. Нажмите **Save**
5. **ВАЖНО**: После добавления переменных необходимо пересобрать проект:
   - Перейдите в **Deployments**
   - Найдите последний деплой
   - Нажмите **Redeploy** или создайте новый коммит

## Проверка

После настройки переменных и пересборки проверьте:
1. Логи деплоя не содержат ошибок подключения к БД
2. Авторизация работает корректно
3. API endpoints отвечают без ошибок 500

## Отладка

Если возникают проблемы:
1. Проверьте логи в Vercel Dashboard → **Deployments** → выберите деплой → **Functions** → выберите функцию → **Logs**
2. Убедитесь, что все переменные добавлены для правильного окружения (Production/Preview)
3. Проверьте, что значения переменных совпадают с локальными (кроме JWT_SECRET, который должен быть уникальным)
