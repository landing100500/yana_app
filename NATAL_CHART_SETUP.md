# Настройка системы расчета натальной карты

## Установка зависимостей

Пакет `swisseph` уже установлен. Для работы Swiss Ephemeris может потребоваться установка нативных зависимостей.

## Создание таблицы в базе данных

Выполните SQL скрипт для создания таблицы:

```bash
mysql -u your_user -p your_database < migrations/create-natal-charts.sql
```

Или выполните SQL вручную в вашей базе данных MySQL.

## Структура данных

Система использует данные из таблицы `user_anketa`:
- `birthDate` - дата рождения (формат: YYYY-MM-DD)
- `birthTime` - время рождения (формат: HH:MM)
- `birthCity` - город рождения

## Расчет натальной карты

При клике на плашку "Натальная карта" на странице чата:

1. Система проверяет, есть ли уже рассчитанная карта
2. Если нет - получает данные из анкеты
3. Получает координаты города через геокодинг API
4. Рассчитывает позиции всех планет, домов, асцендента и MC
5. Сохраняет результат в базу данных
6. Отображает красивую визуализацию

## Рассчитываемые параметры

### Планеты:
- Солнце
- Луна
- Меркурий
- Венера
- Марс
- Юпитер
- Сатурн
- Уран
- Нептун
- Плутон
- Северный узел Луны
- Южный узел Луны

### Дома:
- 12 домов (куспиды)
- Асцендент (ASC)
- Середина неба (MC)

### Система домов:
- Placidus (по умолчанию)

## Визуализация

Натальная карта отображается в виде круговой диаграммы с:
- Знаками зодиака по внешнему кругу
- Домами (линии и номера)
- Планетами (точки с подписями)
- Асцендентом и MC (выделенные линии)
- Легендой с позициями планет в знаках

## API Endpoints

### GET /api/natal-chart/calculate
Проверяет наличие рассчитанной карты

### POST /api/natal-chart/calculate
Рассчитывает и сохраняет натальную карту

## Возможные проблемы

1. **Ошибка при расчете**: Убедитесь, что все данные в анкете заполнены
2. **Город не найден**: Проверьте правильность написания города
3. **Ошибка swisseph**: Может потребоваться установка нативных зависимостей
